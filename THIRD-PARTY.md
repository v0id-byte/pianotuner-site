# Third-Party Software & Assets

Everything below is **self-hosted** from this repository's build output. The site makes no
runtime requests to third-party CDNs — mainland China is our primary market and public CDNs
(and Google Fonts) are unreliable or unreachable there. Since the 2026-09 rebuild, JavaScript
dependencies are bundled by Vite from npm (`package.json` pins exact versions) instead of being
vendored as files.

Since Webflow's acquisition of GreenSock, the entire GSAP toolset — including plugins that were
previously Club GSAP-only, such as SplitText, ScrambleText and CustomEase — is free for
commercial use. No membership, license key, or auth token is required. License headers are
preserved in the minified bundle.

## Fonts

| Component | Retrieved | Source | License |
|---|---|---|---|
| Inter (Latin subset, variable 100–900) | @fontsource-variable/inter, 2026-08-29 | https://github.com/rsms/inter | SIL Open Font License 1.1 |
| Noto Sans SC (subset, variable 100–900) | 2026-09-05 | https://github.com/notofonts/noto-cjk | SIL Open Font License 1.1 |

Files: `fonts/Inter-var.woff2` (47 KB) and `fonts/NotoSansSC-subset.woff2` (~239 KB). The
Noto subset is regenerated by `scripts/subset-fonts.mjs` on every build from the codepoints
actually present in `app/src` (comments stripped), so it only ever contains glyphs the site
uses. The original `NotoSansSC.ttf` lives in `source-assets/fonts/` and is never deployed
(`verify-build` fails on any `.ttf` in the deploy tree). System CJK faces (PingFang SC /
Microsoft YaHei) remain in the fallback stack.

## Explicitly NOT used

**Entropy Piano Tuner** (GPLv3) — we have studied the published behaviour of prior-art tuning
software, but **no EPT source code is copied, ported, linked, or derived from** in this site,
the firmware, or the app. Algorithms as such are not protected by copyright; the source is, and
we do not use it.
